# Fixtures

These fixtures are intentionally tiny placeholder packages for `toy-yard` tests.

- `skyrim_bodyslide` simulates a Skyrim outfit package with BodySlide signals.
- `texture_only` simulates a textures-only package.
- `mixed_pack` simulates a package with mixed content.
- `malformed_archive.7z` is a non-archive file used to exercise failure routing.
